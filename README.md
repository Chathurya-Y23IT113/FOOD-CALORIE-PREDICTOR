##The Website Development project focused on designing and developing a complete web-based application using front-end and back-end technologies. The main objective of this task was to create a user-friendly and responsive website that can collect, store, and manage user information efficiently. During the development process, several important tasks were performed, including creating web pages, designing forms, connecting databases, handling user authentication, and implementing session management. The project helped in understanding the complete workflow of website development from user interface design to server-side processing.The first task performed in this project was designing the front-end interface of the website using HTML and CSS. HTML was used to create the structure of the web pages such as signup page, login page, dashboard page, and logout page. CSS was used to improve the appearance of the website by adding colors, layouts, spacing, fonts, and responsive design. The website was designed in such a way that users could easily navigate through different sections. Forms were created to allow users to enter details such as full name, email, username, password, age, height, and weight. Buttons and input fields were styled properly to provide a better user experience.The next important task was implementing the back-end functionality using PHP. PHP was used as the server-side scripting language to process user requests and interact with the database. The signup page stored user details into the database after validating the input fields. The login system checked whether the entered username and password matched the records stored in the database. Session management was implemented using PHP sessions so that user information remained active until logout. A dashboard page was created to display user details after successful login. Logout functionality was also implemented to destroy the session and securely log the user out from the application.MySQL database was used to store and manage user information. Tables were created to save user details such as username, password, email, age, and other personal information. SQL queries like INSERT, SELECT, and UPDATE were used to manage records in the database. Database connectivity was established using PHP and MySQL integration. This helped in understanding how dynamic websites work with real-time data storage and retrieval.Several tools and technologies were used during the development of this project. HTML and CSS were used for front-end development, while PHP was used for back-end programming. MySQL was used as the database management system. XAMPP server was used to run Apache and MySQL services locally on the system. The project was developed and tested using Visual Studio Code editor because it provides syntax highlighting, debugging support, and easy file management. Google Chrome browser was used for testing and debugging the website functionality. GitHub can also be used to upload and manage the project repository online for version control and collaboration.The editor platform used in this project was Visual Studio Code. It is one of the most popular code editors used for web development because it supports multiple programming languages and extensions. VS Code made coding easier with features like auto-completion, integrated terminal, live server support, and error highlighting. XAMPP control panel was used to manage the local server environment. phpMyAdmin was used to create and manage MySQL databases visually without writing complex commands manually.This website development project can be applied in many real-world applications.
